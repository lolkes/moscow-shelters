# ДОМОЙ — Москва и Московская область

Платформа помощи бездомным животным: каталог приютов и животных, заявки на пристройство, импорт данных из разрешённых публичных источников, дедупликация и модерация.

## Сейчас
- Telegram отключён — подключим позже.
- Основной стек: FastAPI + SQLAlchemy + PostgreSQL/Neon.
- Есть режим SQLite для локального запуска без DATABASE_URL.
- Источники проверяются с учётом robots.txt и безопасного режима.

## Запуск
```bash
pip install -r requirements.txt
python scripts/seed_shelters.py
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте `/` для каталога, `/admin` для панели и `/api/health` для проверки сервера.

## Деплой
Для Render используйте `render.yaml`. В production задайте `DATABASE_URL` от PostgreSQL/Neon и `PUBLIC_BASE_URL`.

## Важно
Платформа не является приютом. Карточки должны содержать ссылку на исходный источник, а перед публикацией данные проходят проверку/модерацию.
